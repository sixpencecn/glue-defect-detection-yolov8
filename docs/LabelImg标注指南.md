# LabelImg 数据标注指南（锂电胶路缺陷）

## 一、标注工具安装

```bash
pip install labelimg
labelimg          # 启动图形界面
```

> 若合成数据已自带 YOLO 标注，可跳过标注步骤，直接进入训练。本指南用于标注**真实产线采集的胶路图片**。

## 二、类别定义（必须与 data.yaml 一致）

| 编号 | 英文名 | 中文名 | 标注要点 |
|------|--------|--------|----------|
| 0 | OK | 正常胶路 | 胶路连续、宽度均匀、无断缺溢 |
| 1 | broken_glue | 断胶 | 胶路中途完全断开，框住断点区域 |
| 2 | lack_glue | 缺胶 | 胶量不足、局部变窄，框住变窄段 |
| 3 | overflow | 溢胶 | 胶量过多溢出胶路，框住溢出区域 |

## 三、标注流程

1. **Open Dir**：打开 `data/raw/images` 目录。
2. **Change Save Dir**：设为 `data/raw/labels`（与图片目录同级）。
3. 切换标注格式：左侧按钮 **PascalVOC / YOLO**，点击切到 **YOLO**（输出 `.txt`）。
4. 快捷键 `W` 画框，框住缺陷区域（尽量贴合缺陷，不要框入过多背景）。
5. 选择类别标签，按 `Ctrl+S` 保存。
6. 全部标注完成后运行划分脚本：
   ```bash
   python scripts/split_dataset.py
   ```

## 四、YOLO 标注格式说明

每张图片对应一个同名 `.txt`，每行一个目标：

```
<class_id>  <x_center>  <y_center>  <width>  <height>
```

- 坐标均为**归一化**值（0~1），相对图片宽高。
- 例如：`1 0.523 0.501 0.180 0.120` 表示断胶，中心在图像中心附近。

## 五、标注质量建议（贴合 2.5D 光源）

- 反光区域容易误判为缺胶：标注时以**胶路是否连续、有无实体胶**为准，而非单纯看亮度。
- 2.5D 光源下胶路边缘有高光，断胶的"断点"通常伴随高光中断，是重要判据。
- 每类建议 ≥ 150 张，缺陷样本尽量覆盖不同光照、不同位置。
- 标注不一致是模型效果差的常见根因，建议 2 人交叉复核。
