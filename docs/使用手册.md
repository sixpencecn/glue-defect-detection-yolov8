# 使用手册

## 一、环境准备

### 1.1 依赖安装

在项目根目录执行：

```bash
pip install -r requirements.txt
```

验证安装：

```bash
python -c "import torch, ultralytics, cv2, PyQt5, openpyxl; print('依赖OK')"
```

> 本项目已在 Python 3.13 + torch 2.15 + ultralytics 8.4 环境验证通过。

### 1.2 目录检查

确认以下目录存在（项目已预建）：`data/raw`、`data/dataset`、`weights`、`outputs`、`docs`。

---

## 二、完整流程（从零到检测）

### 步骤 1：生成数据集

```bash
python scripts/generate_synthetic_data.py --per-class 120
python scripts/split_dataset.py --seed 42
python scripts/augment.py --times 1
```

- 第 1 条：生成 4 类共 480 张 2.5D 光源胶路图像与 YOLO 标注；
- 第 2 条：按 7:2:1 划分到 `data/dataset/`；
- 第 3 条：训练集数据增强（可选，提升泛化）。

### 步骤 2：训练模型

```bash
python -m src.train --epochs 100 --batch 16
```

- CPU 训练较慢，建议减少 epochs（如 30）；GPU 训练用 `--device 0`。
- 训练完成后最佳权重保存为 `weights/best.pt`。

### 步骤 3：推理检测

```bash
# 单图
python -m src.inference --image data/dataset/images/test/broken_glue_0002.jpg

# 批量检测 + 自动导出报表
python scripts/batch_detect_demo.py
```

### 步骤 4：启动界面

```bash
python app.py
```

在界面中：点击「上传图片」→「一键检测」→ 查看判定与缺陷信息 → 在右侧表格查看历史 →「导出Excel报表」。

## 三、各模块使用说明

### 3.1 图像预处理

```python
from src.preprocessing import GluePreprocessor
p = GluePreprocessor()
processed = p.preprocess(image)   # image 为 BGR ndarray
```

参数在 `configs/config.yaml` 的 `image` 段调整。

### 3.2 训练超参

修改 `configs/config.yaml` 的 `train` 段，或命令行覆盖：

```bash
python -m src.train --epochs 50 --batch 8 --imgsz 640 --device cpu
```

### 3.3 调参对比实验

```bash
python -m src.train --compare
```

导出 `outputs/reports/hyperparam_compare.xlsx`。

### 3.4 手动标注真实数据

见 `docs/LabelImg标注指南.md`，标注后放入 `data/raw/images` 与 `data/raw/labels`，重新执行划分与训练。

## 四、常见问题（FAQ）

**Q1：提示 `weights/best.pt` 找不到？**
A：先执行训练步骤生成权重。未训练时程序回退到 COCO 预训练权重，仅跑通流程，检测结果无胶路语义。

**Q2：torch 安装很慢或失败？**
A：参考 PyTorch 官网选择匹配 CUDA 的版本，或使用 CPU 版：`pip install torch --index-url https://download.pytorch.org/whl/cpu`。

**Q3：训练时显存不足（CUDA out of memory）？**
A：减小 batch（如 `--batch 8` 或 4），或换用 yolov8n 模型。

**Q4：检测不到缺陷 / 全是 NG？**
A：确认已用胶路数据训练（非 COCO 权重）；调整 `configs/config.yaml` 中 `inference.conf`（降低阈值可减少漏检）。

**Q5：反光导致误检？**
A：保持界面「启用预处理」勾选（CLAHE 抑制反光）；增加亮度/HSV 数据增强重新训练。

**Q6：界面点击检测无响应？**
A：检测在后台线程执行，首次加载模型需数秒，请稍候。
