# 实验与调参记录

> 本文档记录 YOLOv8 胶路缺陷检测模型的实验设计、超参对比与结果分析，用于毕设"实验与结果分析"章节。

## 一、实验设置

### 1.1 数据集

- 数据来源：2.5D 光源胶路合成数据集（物理成像近似）+ 真实数据标注接口；
- 类别数：4（OK / 断胶 / 缺胶 / 溢胶）；
- 划分比例：训练集 70% / 验证集 20% / 测试集 10%（`--seed 42` 保证可复现）；
- 数据增强：亮度扰动、高斯噪声、HSV 扰动、水平/垂直翻转。

### 1.2 环境与超参

| 项目 | 配置 |
|------|------|
| 模型 | YOLOv8n（yolov8n.pt） |
| 输入分辨率 | 640 × 640 |
| Epochs | 100（patience=20 早停） |
| Batch size | 16 |
| 初始学习率 lr0 | 0.01 |
| 优化器 | SGD（ultralytics 默认） |
| IoU（训练） | 0.7 |
| 随机种子 | 42 |

### 1.3 评价指标

- **Precision（精确率）**：预测为正样本中真正为正的比例；
- **Recall（召回率）**：真实正样本中被正确检出的比例；
- **mAP@0.5**：IoU=0.5 时的平均精度均值；
- **mAP@0.5:0.95**：IoU 从 0.5 到 0.95 的平均 mAP；
- **单张检测耗时**：推理延迟（ms）。

## 二、基线实验结果（已完成）

使用合成数据集（每类 60 张，共 240 张，划分 168/48/24），以 YOLOv8n、imgsz=320、batch=8、CPU 训练 **3 轮**（冒烟测试）得到的真实结果：

| 指标 | 数值 |
|------|------|
| Precision | 0.9202 |
| Recall | 0.8972 |
| mAP@0.5 | 0.9739 |
| mAP@0.5:0.95 | 0.6718 |

训练曲线显示 loss 持续下降、mAP 稳步上升，3 轮已达 mAP@0.5≈0.97，验证了数据集标注正确、模型可正常收敛。**说明**：此为快速验证结果，正式实验请将 epochs 提升至 100 以获得更稳定的精度。训练曲线见 `weights/runs/glue_yolov8/results.png`。

### 实验一：预处理对检测效果的影响

为验证预处理（尤其 CLAHE 亮度均衡）对 2.5D 反光场景的作用，设置两组对照：

| 实验组 | 预处理 | mAP@0.5 | 说明 |
|--------|--------|---------|------|
| A | 无 | 待填入 | 原始图像直接检测 |
| B | ROI+高斯+CLAHE | 待填入 | 完整预处理流水线 |

**分析方法**：对比两组 mAP 与漏检数量。预期 B 组在小目标与反光区域的召回率更高。实验中可通过 `python -m src.inference --image xxx --no-preprocess` 关闭预处理做对照。

## 3、实验二：置信度阈值（conf）对比

置信度阈值决定"多可信才输出检测框"。阈值过低误检多，过高漏检多。

运行方式：

```bash
python -m src.train --compare
```

结果自动导出 `outputs/reports/hyperparam_compare.xlsx`。记录模板：

| conf | mAP@0.5 | Precision | Recall | 分析 |
|------|---------|-----------|--------|------|
| 0.15 |  |  |  | 误检偏多 |
| 0.25 |  |  |  | 默认推荐值 |
| 0.35 |  |  |  | 平衡 |
| 0.45 |  |  |  | 漏检风险上升 |

**预期结论**：胶路缺陷为小目标，置信度不宜过高；推荐 conf=0.25~0.35。

## 四、实验三：IoU 阈值对比

IoU 阈值用于 NMS（非极大值抑制），控制重叠框的抑制强度。

| IoU | mAP@0.5 | 分析 |
|-----|---------|------|
| 0.35 |  | 抑制强，可能丢失邻近缺陷 |
| 0.45 |  | 默认推荐值 |
| 0.55 |  |  |
| 0.65 |  | 抑制弱，重叠框残留 |

**预期结论**：推荐 IoU=0.45~0.55。

## 八、复现实验步骤

```bash

# 3. 调参对比实验(需已训练权重)

# 4. 批量检测 + 导出报表
python scripts/batch_detect_demo.py
```
