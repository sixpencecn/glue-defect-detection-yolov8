# 锂电池胶路缺陷检测系统 — 项目设计与实现

## 摘要

针对锂电池封装打胶工序中胶路质量检测难题，本项目设计并实现了一套基于 YOLOv8 的自动化视觉检测系统。系统面向康视达公司 2.5D 光源胶检业务场景，通过图像预处理抑制胶面反光干扰，采用 YOLOv8 目标检测模型识别正常胶路、断胶、缺胶、溢胶 4 类状态，并集成数据集构建、模型训练调参、推理检测、统计报表与 PyQt 可视化界面，形成完整的工程闭环。实验表明，该方法能有效降低传统视觉方法在反光与光照波动下的误检漏检率，满足毕设中等难度要求与企业实际需求。

**关键词**：锂电池；胶路缺陷检测；YOLOv8；2.5D 光源；图像处理；PyQt

---

## 一、项目背景与意义

### 1.1 业务背景

在锂电池封装工艺中，打胶工序的胶路质量直接关系到电池的密封性能与安全。胶路若出现断胶、缺胶，会导致密封失效、电解液泄漏；溢胶则可能污染极耳或影响后续装配。因此，对胶路质量进行在线全检具有重要意义。

康视达公司当前承接的工业视觉项目中，锂电胶检属于高频项目。产线采用 **2.5D 条状光源**成像：相比普通面光源，2.5D 光源能在胶路表面形成明显的明暗条纹与立体高光，突出胶路的三维形貌，有利于判断胶量状态。但同时也带来挑战：**胶面反光强烈、光照波动大**，导致传统基于阈值分割、轮廓检测的方法容易误检漏检，鲁棒性差。

### 1.2 技术选型

目标检测算法分为两阶段（如 Faster R-CNN）与单阶段（如 YOLO、SSD）。考虑到产线对**实时性**与**部署便捷性**的要求，本项目选用 **YOLOv8**：

- **速度快**：单阶段检测，满足在线检测帧率要求；
- **精度高**：采用 Anchor-Free 与 CIoU 损失，小目标检测效果好；
- **生态完善**：ultralytics 库提供训练、验证、导出一体化接口，便于调参与部署；
- **版本适中**：yolov8n/s 模型轻量，适合毕设在普通 GPU 上训练。

### 1.3 项目意义

- **工程价值**：形成从数据采集到报表导出的完整检测系统，可直接对接产线需求；
- **学术价值**：验证深度学习方法在反光工业场景下的缺陷检测有效性；
- **教学价值**：中等难度、模块清晰，适合作为计算机专业毕业设计。

## 二、需求分析

### 2.1 功能需求

系统包含 7 个核心模块：

1. **图像采集模块**：支持工业相机采集 / 本地图片导入，适配 2.5D 光源胶路图像；
2. **图像预处理模块**：ROI 裁剪、高斯滤波、亮度均衡，降低反光干扰；
3. **数据集构建模块**：LabelImg 标注、数据增强、训练集/验证集/测试集划分；
4. **YOLOv8 训练模块**：模型训练、超参调优、置信度与 IoU 对比实验；
5. **推理检测模块**：输入图片，输出缺陷框、类别、置信度；
6. **数据统计与导出模块**：记录 OK/NG、缺陷类型、检测时间，导出 Excel 报表，保存缺陷截图；
7. **PyQt 可视化界面**：上传图片、一键检测、查看历史记录。

### 2.2 检测类别定义

| 编号 | 英文名 | 中文名 | 判定标准 |
|------|--------|--------|----------|
| 0 | OK | 正常胶路 | 胶路连续、宽度均匀、无缺陷 |
| 1 | broken_glue | 断胶 | 胶路中途完全断开，存在断点 |
| 2 | lack_glue | 缺胶 | 胶量不足，胶路局部变窄或缺失 |
| 3 | overflow | 溢胶 | 胶量过多，胶体外溢到胶路两侧 |

### 2.3 非功能需求

- **实时性**：单张检测耗时控制在毫秒级；
- **鲁棒性**：对光照波动、反光具有一定适应能力；
- **可追溯性**：检测记录持久化，支持导出与回溯；
- **易用性**：图形界面操作简单，无需命令行基础。

## 四、详细设计与实现

### 4.1 图像预处理模块

针对 2.5D 光源反光问题，设计三级预处理流水线：

1. **ROI 裁剪**：裁去与胶路无关的背景区域，减少干扰并降低计算量；
2. **高斯滤波**：使用 3×3 高斯核对图像平滑，抑制 CMOS 传感器细颗粒噪声；
3. **CLAHE 亮度均衡**：在 LAB 色彩空间对 L 通道进行限制对比度自适应直方图均衡，压制局部过曝反光、提升暗部胶路细节。相比全局直方图均衡，CLAHE 避免噪声放大，更适合光照不均的工业场景。

实现见 `src/preprocessing.py`，关键参数（高斯核、CLAHE 裁剪限、网格大小）均可在 `configs/config.yaml` 中配置。

### 4.2 数据集构建模块

由于真实产线数据涉密，项目提供 **2.5D 光源胶路图像合成器**（`scripts/generate_synthetic_data.py`），通过物理成像近似模拟：

- 暗色金属基底 + 低频纹理模拟电池顶盖；
- 周期性明暗条纹模拟 2.5D 条状光源；
- 圆凸截面剖面（`sqrt(1-dy²)`）模拟胶条立体高光；
- 方向性明暗模拟光源入射角；
- 分别注入断胶（断开）、缺胶（变窄）、溢胶（变宽+胶瘤）特征，并输出 YOLO 格式标注。

真实数据场景可直接使用 LabelImg 标注（YOLO 格式），按 7:2:1 划分数据集。数据增强包括亮度扰动、高斯噪声、HSV 色域扰动与水平/垂直翻转，用于模拟光照波动与相机噪声，提升模型泛化能力。

### 4.3 YOLOv8 训练模块

- **模型**：YOLOv8n（轻量版），输入分辨率 640×640；
- **超参**：epochs=100，batch=16，lr0=0.01，IoU=0.7，patience=20（早停）；
- **损失**：CIoU 边界框损失 + 分类交叉熵；
- **输出**：保存最佳权重 `weights/best.pt`，训练曲线与指标存于 `weights/runs/`。

训练脚本支持命令行覆盖超参，便于快速迭代。

### 4.4 推理检测模块

`GlueDetector` 封装完整推理流程：读取图像 →（可选）预处理 → YOLOv8 预测 → 解析检测框 → 绘制标注图 → OK/NG 判定（检出任一非 OK 类即判 NG）→ 返回结果字典（含类别、置信度、框坐标、耗时）。支持单图、目录批量与 numpy 数组（相机帧）三种输入。

### 4.5 统计导出模块

`DetectionRecorder` 记录每次检测的序号、时间、来源、判定、缺陷类型、置信度、耗时等信息，持久化到 JSON。导出 Excel 时生成两个工作表：**检测明细**（逐条记录）与**统计汇总**（总数、OK/NG 数、不良率、平均耗时、各缺陷类型计数）。NG 图片自动保存带检测框的截图，便于质量追溯。

### 4.6 PyQt 可视化界面

`MainWindow` 提供上传图片、一键检测、历史记录表格、导出报表、清空历史等功能。检测在 `QThread` 后台线程执行，避免界面卡顿；检测结果以文字状态与彩色标注图呈现，OK 绿色 / NG 红色直观提示。

## 五、关键技术难点与解决方案

| 难点 | 解决方案 |
|------|----------|
| 2.5D 光源反光、光照波动大 | CLAHE 亮度均衡 + 亮度/HSV 数据增强，提升模型对光照变化的鲁棒性 |
| 胶路缺陷目标细小 | 640 高分辨率输入 + YOLOv8 小目标检测能力 + 针对性标注 |
| 真实数据获取困难 | 物理成像近似合成 2.5D 胶路数据，保证毕设可复现 |
| 界面检测卡顿 | 检测逻辑放入 QThread 后台线程 |
| 检测结果难追溯 | JSON 历史 + Excel 明细/汇总 + NG 截图三重记录 |

## 七、总结与展望

本项目完成了一套基于 YOLOv8 的锂电池胶路缺陷检测系统，覆盖数据构建、预处理、训练调参、推理检测、统计导出与可视化界面全流程，贴合康视达 2.5D 光源胶检真实业务。系统模块清晰、难度适中，适合作为计算机专业毕业设计。

后续可从以下方向改进：
1. 引入真实产线数据并做领域适配训练，进一步提升精度；
2. 接入工业相机 SDK，实现在线实时检测；
3. 模型量化与 TensorRT 加速，满足产线高帧率部署；
4. 增加缺陷分类细分（如按严重程度分级）。
